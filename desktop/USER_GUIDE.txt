Photo Assist 스타일 결과 수집기 — Windows x64

1. ZIP을 모두 압축 해제합니다.
2. PhotoAssistCollector.exe를 실행합니다.
   EXE 옆의 _internal 폴더도 반드시 함께 유지합니다.
   Python, Node.js, Docker, Appium, Git을 별도 설치하지 않아도 되게 묶었습니다.
3. 폰을 USB로 연결하고 USB 디버깅 및 이 PC 연결을 허용합니다.
   PC에 따라 삼성 USB 드라이버가 필요할 수 있습니다.
4. 기기 찾기를 누릅니다.
5. 처음에는 [처음 한 번 · 버튼 설정] 탭의 안내대로 버튼을 지정합니다.
6. 실행 탭에서 폴더와 원본을 선택하고 첫 사진/첫 스타일부터 확인합니다.
7. 동작과 저장 위치 확인 후 새 작업으로 전체 스타일을 실행합니다.

설정과 로그: %LOCALAPPDATA%\PhotoAssistCollector
사진 결과: 원본과 같은 휴대전화 폴더. 다른 폴더에 저장되면 중단합니다.
실제 폰에서 품질 평가는 사람이 합니다.

사용 중 알아둘 점
- 폰은 잠금 해제 및 Photo Assist 생성용 인터넷 연결 상태를 유지합니다.
- 실행 중 다른 사진 생성/촬영/다운로드/동기화를 병행하지 마세요.
- 중지는 다음 클릭을 막으며, 이미 요청된 AI 생성을 취소하지는 않습니다.
- 화면 읽기 시 uiautomator2의 보조 프로그램이 폰에 배치·실행될 수 있습니다.
- 원본 삭제/이동/강제 덮어쓰기, 갤러리 강제 종료, 루팅을 수행하지 않습니다.
- 모든 버튼이 UI 정보에 노출되는지는 기기에서 확인해야 합니다.
- 실제 S26+에서 전체 실행 검증은 아직 완료되지 않았습니다.
- 처음 목록에 없는 스타일은 스와이프 횟수 또는 목록 펼치기 버튼을 설정합니다.
  세로 목록/복잡한 분류 경로는 추가 조정이 필요할 수 있습니다.
- 프로그램은 코드서명되지 않은 개발 버전입니다. PC 정책이 차단하면 우회하지 말고
  담당자에게 해당 실행 파일의 사용 허용 여부를 확인하세요.

유지보수 담당자
- app.py: 사용자 화면 및 설정
- automation.py: 기기 연결, 버튼 읽기, 실행 및 저장 확인
- tests/: 기기 없는 자동 테스트
- build.ps1: 윈도우 빌드
저장소 Actions의 Build Windows EXE에서도 동일 빌드를 수행할 수 있습니다.
